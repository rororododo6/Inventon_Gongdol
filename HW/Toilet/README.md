## 🛠️ 하드웨어 구성

### 라즈베리파이 4 (메인 시스템)
- **모델**: Raspberry Pi 4B (4GB 이상 권장)
- **카메라**: PI 카메라 모듈 v2/v3
- **해상도**: 640x480 (최적화됨)
- **통신**: UART (GPIO 14/15)
- **성능**: 3-6 FPS, 98% 탐지 정확도

### Arduino Uno (하드웨어 제어)
- **모델**: Arduino Uno R3
- **펌웨어**: v1.3.1 (클린코딩 버전)
- **통신**: 시리얼 (115200 baud)
- **제어**: 온습도 센서, 서보모터, 스테핑 모터

### 센서 및 액추에이터
| 부품 | 모델 | 핀 번호 | 기능 |
|------|------|---------|------|
| 온습도 센서 | DHT11 | D2 | 환경 모니터링 |
| 서보모터 | SG90 | D9 | 모래 밀어내기 |
| 스테핑 모터 | 28BYJ-48 | D5-D8 | 똥 치우기 |
| 드라이버 보드 | ULN2003 | D5-D8 | 스테핑 모터 제어 |
| 긴급 정지 버튼 | 푸시 버튼 | D3 | 안전 시스템 |
| 상태 LED | 5mm LED | D13 | 시스템 상태 표시 |
| 부저 | 액티브 부저 | D11 | 알림음 |

## 🔄 3단계 청소 프로세스

### 1단계: 모래 밀어내기 (서보모터)
```
SG90 서보모터 제어
├── 0° → 90° → 0° (20회 반복)
├── 소요시간: 약 20초
└── 목적: 새똥 위 모래 제거
```

### 2단계: 똥 치우기 (스테핑 모터)
```
28BYJ-48 스테핑 모터 제어
├── 전진: 3바퀴 회전 (6144 스텝)
├── 대기: 1초
├── 후진: 원위치 복귀 (-6144 스텝)
└── 목적: 새똥 수집 및 제거
```

### 3단계: 시스템 초기화
```
소프트웨어 초기화
├── 누적 탐지 영역 데이터 삭제
├── 청소 카운터 증가
└── 시스템 상태 리셋
```

## 🔧 하드웨어 설정

### 전원 공급
- **라즈베리파이**: 5V 3A 어댑터 (USB-C)
- **Arduino**: USB 전원 또는 DC 7-12V
- **서보모터**: 5V (Arduino 5V 핀)
- **스테핑 모터**: 5V (ULN2003 보드)

### 배선 가이드
```
라즈베리파이 → Arduino
├── GPIO 14 (TXD) → Arduino RX (D0)
├── GPIO 15 (RXD) → Arduino TX (D1)
└── GND → GND (공통 접지)

Arduino → 센서/액추에이터
├── D2 → DHT11 데이터 핀
├── D3 → 긴급 정지 버튼
├── D5-D8 → ULN2003 IN1-IN4
├── D9 → SG90 서보모터 신호선
├── D11 → 부저 양극
└── D13 → LED 양극
```

## 📊 성능 지표

### 시스템 성능
- **탐지 정확도**: 98% 이상 (커스텀 모델)
- **청소 성공률**: 95% 이상

### 하드웨어 성능
- **서보모터**: 0° ↔ 90° 이동 시간 0.5초
- **스테핑 모터**: 12 RPM 청소 속도

## 🔍 문제 해결

### 일반적인 문제
- **시리얼 통신 안됨**: 케이블 연결 및 포트 확인
- **서보모터 작동 안됨**: 전원 공급 및 신호선 확인
- **스테핑 모터 떨림**: ULN2003 보드 전원 확인
- **센서 데이터 오류**: DHT11 연결 및 라이브러리 확인

### 성능 최적화
- **통신 지연**: 버퍼 크기 조정 (현재 512 bytes)
- **모터 속도**: 청소 품질 vs 속도 트레이드오프
- **메모리 사용**: Arduino 메모리 모니터링 (freeMemory() 함수)
