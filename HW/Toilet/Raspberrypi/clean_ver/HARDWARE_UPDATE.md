## 🏗️ 하드웨어 구성

### 📍 **핀 연결**
```
DHT11 센서: Pin 2
360도 서보모터 (MG996R): Pin 6  
긴급정지 버튼: Pin 3 (인터럽트)
상태 LED: Pin 7
부저: Pin 5
쓰레기 비움 시스템: Pin 4 (전류 감지)
```

### 🔄 **360도 서보모터 제어**
- **정지**: 1500us PWM
- **앞으로 회전**: 1700us PWM  
- **뒤로 회전**: 1300us PWM
- **청소 시간**: 3초씩 앞뒤 회전

---

## 🗑️ 쓰레기 비움 시스템

### 🔌 **전류 감지 방식**
```
전류 흐름 (HIGH) → 정상 상태
전류 끊김 (LOW)  → 쓰레기통 제거 감지
```

### ⏰ **자동 초기화 로직**
1. **전류 끊김 감지** → 쓰레기통 제거 확인
2. **10초 대기** → 충분한 시간 확보
3. **전류 재연결** → 쓰레기통 다시 설치
4. **자동 초기화** → 청소 횟수 0으로 리셋

### 📊 **상태 메시지**
```json
// 전류 끊김
{"info":"POWER_DISCONNECTED_TRASH_SYSTEM"}

// 자동 초기화 성공
{"alert":"CLEANING_CYCLES_AUTO_RESET","off_duration":12000}

// 너무 빨리 재연결
{"info":"POWER_RECONNECTED_TOO_EARLY","off_duration":5000,"required":10000}
```

## 🤖 JSON 통신 프로토콜

### 📨 **지원 명령어**
| 명령어 | 기능 | 파라미터 | 응답 |
|--------|------|----------|------|
| `ping` | 연결 테스트 | - | `{"response":"pong"}` |
| `sensor` | 센서 데이터 | - | 온도/습도/상태 |
| `servo` | 360도 서보 제어 | `direction: 0/1/-1` | 제어 상태 |
| `led` | LED 제어 | `state: true/false` | LED 상태 |
| `clean` | 새장 청소 | - | 청소 진행 상태 |
| `status` | 시스템 상태 | - | 전체 시스템 정보 |
| `trash` | 쓰레기 시스템 확인 | - | 전류/초기화 상태 |

### 📋 **명령어 예시**
```json
// 서보 앞으로 회전
{"c":"servo","d":1}

// LED 켜기  
{"c":"led","s":true}

// 청소 시작
{"c":"clean"}
```

## 🚀 설치 및 사용법

### 1️⃣ **아두이노 설정**
```cpp
// clean_ver/arduino_code_improved.ino 업로드
// 필요 라이브러리: ArduinoJson, DHT11, Servo
```

### 2️⃣ **라즈베리파이 설정**
```python
from managers.arduino_client_improved import ArduinoClientImproved

# 아두이노 연결
client = ArduinoClientImproved(port='/dev/ttyUSB0', baudrate=115200)
client.connect()

# 360도 서보 제어
client.control_servo(1)   # 앞으로
client.control_servo(-1)  # 뒤로
client.control_servo(0)   # 정지

# 청소 실행
client.perform_cage_cleaning()

# 전류 상태 확인
status = client.check_power_status()
```

### 3️⃣ **시리얼 포트 설정**
- **Linux**: `/dev/ttyUSB0`, `/dev/ttyACM0`
- **Windows**: `COM3`, `COM4`, `COM5`
- **속도**: 115200 baud
