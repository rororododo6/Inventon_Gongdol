# 🔌 YOLOv11s 새똥 탐지 시스템 하드웨어 연결 가이드

라즈베리파이 기반 YOLOv11s 새똥 탐지 및 자동 청소 시스템의 완전한 하드웨어 연결 가이드입니다.

## 📂 프로젝트 구조
```
Arduino/
├── 라즈베리파이/              # 라즈베리파이 전용 폴더
│   ├── main.py                # 메인 런처 (시작점)
│   ├── pi_camera_client.py    # PI 카메라 클라이언트 (권장)
│   ├── gpio_uart_client.py    # GPIO UART 클라이언트
│   ├── demo_test.py          # 테스트 데모
│   └── README.md             # 라즈베리파이 전용 문서
├── src/main.cpp              # Arduino 메인 코드
├── include/functions.h       # Arduino 헤더 파일
├── platformio.ini           # Arduino 프로젝트 설정
├── requirements.txt         # Python 패키지 목록
└── HARDWARE_CONNECTION.md   # 이 파일
```

## 🔌 상세 연결 가이드

### 1️⃣ 라즈베리파이 4 기본 설정

#### 📦 라즈베리파이 준비
```bash
# 1. Raspberry Pi OS 설치 (Raspberry Pi Imager 사용)
# 2. SSH 및 VNC 활성화
# 3. 네트워크 설정 (Wi-Fi 또는 이더넷)
# 4. 시스템 업데이트
sudo apt update && sudo apt upgrade -y
```

#### 📷 PI 카메라 모듈 연결
```
PI 카메라 모듈 → 라즈베리파이 CSI 포트 (Camera Serial Interface)
```

**연결 방법:**
1. 라즈베리파이 전원 끄기
2. CSI 포트의 플라스틱 클립 들어올리기
3. 카메라 플렉스 케이블의 금속 접점이 아래를 향하도록 삽입
4. 플라스틱 클립 다시 눌러서 고정
5. 전원 켜기

**카메라 활성화 및 테스트:**
```bash
# 카메라 활성화
sudo raspi-config
# 3 Interface Options → I1 Camera → Yes

# 시스템 재부팅
sudo reboot

# PI 카메라 라이브러리 설치
sudo apt install python3-picamera2 libcamera-apps

# 카메라 테스트
libcamera-hello --timeout 5000

# 사진 촬영 테스트
libcamera-still -o test.jpg
```

### 2️⃣ Arduino Uno 연결

#### 🔗 라즈베리파이 ↔ Arduino 연결
```
라즈베리파이 USB 포트 → USB A to B 케이블 → Arduino Uno
```

**시리얼 포트 확인:**
```bash
# 연결된 시리얼 포트 확인
ls /dev/ttyUSB* /dev/ttyACM*

# 권한 설정
sudo usermod -a -G dialout $USER
```

### 3️⃣ DHT11 센서 연결

#### 📊 DHT11 센서 → Arduino 연결
```
DHT11 센서    Arduino Uno
┌─────────┐   ┌─────────────┐
│   VCC   │──→│     5V      │
│   DATA  │──→│ Digital Pin 2│
│   GND   │──→│     GND     │
└─────────┘   └─────────────┘
```

**연결 세부사항:**
- **VCC**: 5V 전원 공급
- **DATA**: Digital Pin 2 (풀업 저항 10kΩ 권장)
- **GND**: 그라운드 연결

#### 🔧 풀업 저항 연결 (권장)
```
Digital Pin 2 ──┬── DHT11 DATA
                │
               10kΩ
                │
               5V
```

### 4️⃣ 28BYJ-48 스테핑 모터 + ULN2003 연결

#### 🎛️ ULN2003 드라이버 → Arduino 연결
```
ULN2003 모듈    Arduino Uno
┌─────────────┐ ┌─────────────┐
│    IN1      │←│Digital Pin 5│
│    IN2      │←│Digital Pin 6│
│    IN3      │←│Digital Pin 7│
│    IN4      │←│Digital Pin 8│
│    VCC      │←│     5V      │
│    GND      │←│     GND     │
└─────────────┘ └─────────────┘
```

#### 🔄 28BYJ-48 모터 → ULN2003 연결
```
28BYJ-48 모터 → ULN2003 모듈의 모터 소켓에 직접 연결
(5핀 커넥터 사용)
```

### 5️⃣ 전원 공급 시스템

#### ⚡ 라즈베리파이 전원
```
라즈베리파이 4 ← 5V 3A 전원 어댑터 (USB-C)
```

#### 🔋 Arduino 전원
```
Arduino Uno ← USB 전원 (라즈베리파이 USB 포트에서 공급)
또는
Arduino Uno ← 9V 외부 전원 어댑터 (고성능 모터 사용 시)
```

## 🔍 문제 해결 가이드

### 📷 PI 카메라 관련 문제
```bash
# 카메라 인식 확인
libcamera-hello --timeout 2000

# 카메라 연결 상태 확인
dmesg | grep -i camera

# 카메라 설정 확인
vcgencmd get_camera

# 권한 설정
sudo usermod -a -G video $USER

# 카메라 케이블 연결 확인사항:
# 1. 플렉스 케이블이 CSI 포트에 단단히 고정되었는지 확인
# 2. 금속 접점이 올바른 방향인지 확인 (아래쪽)
# 3. 케이블 손상 여부 확인
```

### 🔌 Arduino 연결 문제
```bash
# 시리얼 포트 미인식
sudo dmesg | grep tty
sudo chmod 666 /dev/ttyUSB0

# 권한 오류
sudo usermod -a -G dialout $USER
```

### 🌡️ DHT11 센서 오류
- **데이터 핀 연결 확인**
- **전원 공급 확인 (5V)**
- **풀업 저항 연결 확인**

### 🔄 스테핑 모터 오류
- **ULN2003 핀 순서 확인**
- **전원 공급 확인 (5V)**
- **모터 커넥터 연결 확인**
